Guía del proyecto Polylla3D

Cómo funciona PolyllaFace

Una lectura visual, paso a paso, del programa que transforma una malla tetraédrica en una colección de poliedros usando caras como fronteras de agrupación.

Leyenda datos y topología selección y recorrido reparación salida y estadísticas decisiones o errores

1. La idea general

Una malla tetraédrica está formada por muchos tetraedros conectados por caras. PolyllaFace decide qué caras deben actuar como fronteras y agrupa los tetraedros que quedan entre ellas. Cada grupo se convierte en un objeto Polyhedron.

1. LeerSe cargan nodos, caras y tetraedros desde los archivos de TetGen.
2. MedirSe calcula una métrica para elegir una cara por tetraedro.
3. RecorrerUn DFS agrupa tetraedros cruzando solo caras internas.
4. Reparar y exportarSe corrigen barreras y se escribe un archivo OFF.

Contrato importante: FaceTetrahedronMesh necesita que los índices escritos por TetGen sean compatibles con las posiciones de las listas. Los archivos generados por la configuración actual ya cumplen ese contrato.

3. Las estructuras de datos

Vertex

Representa un nodo con índice i y coordenadas x, y, z. Los objetos viven en mesh.node_list.

Face

Guarda tres vértices, hasta dos tetraedros vecinos (n1, n2), sus tres aristas, área y si es frontera.

Tetrahedron

Guarda cuatro vértices, cuatro caras y cuatro vecinos. La posición es esencial: tetra.faces[i] corresponde a tetra.neighs[i].

Polyhedron

Es el resultado: una lista de índices de tetraedros y otra de caras frontera. También registra si fue reparado o clasificado como convexo.

Durante save_faces, las caras se buscan con los tres índices ordenados. Así, el programa puede reconocer la misma cara aunque los vértices aparezcan en órdenes diferentes.

4. El constructor: el flujo principal

El constructor de PolyllaFace hace prácticamente todo el algoritmo. Al terminar, polyhedral_mesh ya contiene los poliedros.

PolyllaFace.__init__
self.mesh = mesh
self.flag = flag

# Cada flag apunta a una estrategia de selección.
self.FLAGS = {
    'r': self.calculate_max_incircle_faces,
    'R': self.calculate_max_circumcircle_faces,
    'tra': self.calculate_max_triangle_aspect_faces,
    'are1': self.calculate_max_aspect_ratio_e1_faces,
    'are2': self.calculate_max_aspect_ratio_e2_faces,
    'a': self.calculate_max_area_faces,
}

self.longest_faces = self.FLAGS[flag]()
self.seed_tetra = self.calculate_seed_tetrahedrons()
self.bitvector_frontier_faces = self.calculate_frontier_faces()

self.visited_tetra = [False] * mesh.n_tetrahedrons
self.polyhedral_mesh = []

longest_faces no contiene índices globales de caras. Para cada tetraedro contiene un índice local entre 0 y 3, que indica cuál de sus cuatro caras fue seleccionada.

El programa no usa una única definición de “mejor cara”. El parámetro flag selecciona la estrategia:

Área triangular
# A = 1/2 * norma((v2 - v1) x (v3 - v1))
area = np.linalg.norm(np.cross(av2 - av1, av3 - av1))

Lectura del algoritmo: una vez calculado el valor de cada cara, el programa compara las cuatro caras de cada tetraedro y guarda la posición de la mayor. Los empates se resuelven con la primera coincidencia.

6. Caras frontera y tetraedros semilla

calculate_frontier_faces crea un vector booleano del tamaño de face_list. Una cara es frontera si está en el borde de la malla o si ninguno de sus tetraedros la eligió como cara máxima.

Fronteras
if n1 == -1 or n2 == -1:
    frontier_faces.append(True)
else:
    frontier_faces.append(
        f != longest_face_n1 and f != longest_face_n2
    )

Después, calculate_seed_tetrahedrons localiza tetraedros desde los que puede comenzar un grupo. Busca caras de borde o caras que fueron seleccionadas por ambos tetraedros vecinos.

7. DFS: cómo se forman los poliedros

DepthFirstSearch parte de un tetraedro semilla. Marca el tetraedro como visitado y examina sus cuatro caras:

  • Si la cara es frontera, se añade a la superficie del poliedro.
  • Si es interna, se cruza hacia el tetraedro vecino.
  • Si el vecino ya fue visitado, no se repite el recorrido.
Recorrido
def DepthFirstSearch(self, polyhedron, polyhedron_tetras, tetra):
    self.visited_tetra[tetra] = True
    polyhedron_tetras.append(tetra)

    for i in range(4):
        face_id = self.mesh.tetra_list[tetra].faces[i]
        if self.bitvector_frontier_faces[face_id]:
            polyhedron.append(face_id)
        else:
            next_tetra = self.mesh.tetra_list[tetra].neighs[i]
            if not self.visited_tetra[next_tetra]:
                self.DepthFirstSearch(
                    polyhedron, polyhedron_tetras, next_tetra
                )

La pareja polyhedron_tetras / polyhedron acumula respectivamente los tetraedros interiores y las caras que delimitan el resultado.

8. Caras barrera y reparación

Una cara frontera repetida dentro de un mismo poliedro indica una “barrera”: la superficie se ha plegado o se ha encontrado con una configuración que necesita dividirse.

Detección
def count_barrierFaces(self, polyhedron):
    repeated = [k for k, v in Counter(polyhedron).items() if v > 1]
    if len(repeated) > 0:
        self.n_barrier_faces += len(repeated)
        self.polyhedra_with_barriers += 1
    return len(repeated)

detectBarrierFaceTips obtiene las aristas de las caras repetidas y busca una arista que pueda servir como punto de separación. repairPhase convierte una cara interna adecuada en nueva frontera y vuelve a ejecutar un DFS desde los tetraedros afectados.

Resultado: los poliedros reparados se marcan con was_repaired = True. La reparación no cambia los archivos de TetGen; cambia únicamente la agrupación que mantiene PolyllaFace en memoria.

9. Exportación y análisis

printOFF_polyhedralmesh

Escribe una superficie OFF con los vértices de la malla y las caras de cada poliedro. También ajusta la orientación de las caras con ccw_check.

printOFF_each_poly

Genera un OFF por poliedro, usando solo los vértices que pertenecen a sus tetraedros.

printVISF_polyhedralmesh

Escribe una representación VISF que conserva la lista de poliedros y sus caras.

writePolygonFile

Guarda una descripción textual de los poliedros no convexos.

get_info resume la ejecución: número de poliedros, barreras, poliedros reparados, poliedros que siguen siendo tetraedros, caras y aristas utilizadas.

10. El bloque main

Cuando se ejecuta el archivo directamente, el bloque final selecciona una malla por su nombre base:

src/PolyllaFace.py
if __name__ == "__main__":
    folder = "data\\"
    file = "1000random.1"
    filename = folder + file

    node_file = filename + ".node"
    ele_file = filename + ".ele"
    face_file = filename + ".face"

    mesh = FaceTetrahedronMesh(node_file, face_file, ele_file)
    polylla_mesh = PolyllaFace(mesh)
    polylla_mesh.printOFF_polyhedralmesh(filename + "_polyhedral_mesh.off")
    polylla_mesh.get_info()

Se ejecuta desde la raíz del proyecto:

PowerShell
python src/PolyllaFace.py

Para cambiar de conjunto, basta con modificar file a 1000poisson.1, 1000semiuniform.1 o 1000uniform.1. No se debe añadir otra vez .node, porque el programa lo agrega automáticamente.

11. Uso desde un notebook

Python
from src.newMesh import FaceTetrahedronMesh
from src.PolyllaFace import PolyllaFace

bases = ["1000random.1", "1000poisson.1", "1000semiuniform.1", "1000uniform.1"]

for base in bases:
    prefix = "data/" + base
    mesh = FaceTetrahedronMesh(
        prefix + ".node",
        prefix + ".face",
        prefix + ".ele",
    )
    polylla = PolyllaFace(mesh, flag="r")
    polylla.get_info()
    polylla.printOFF_polyhedralmesh(
        prefix + "_polyhedral_mesh.off"
    )

12. Qué observar en una ejecución

  • “Reading vertex/face/tetra file”: la entrada fue encontrada y leída.
  • “Tetraedralization ready”: la conectividad de la malla se construyó.
  • “Number of polyhedrons”: la agrupación terminó.
  • “writing OFF file”: se creó la superficie para inspección en MeshLab o PyVista.
Nota geométrica: FaceTetrahedronMesh guarda la longitud de una arista como distancia al cuadrado. El comportamiento actual funciona con los datos probados, pero las métricas que interpretan ese valor como longitud deben considerarse una convención específica de este proyecto.
