1. Qué hace el notebook

El cuaderno trabaja dentro del cubo unitario [0, 1]^3. Produce puntos con cuatro estrategias diferentes y convierte esos puntos en tetraedros. Luego visualiza las mallas, las guarda como archivos compatibles con TetGen y ejecuta TetGen para obtener la conectividad final.

1. PrepararImporta NumPy, SciPy, PyVista, TetGen, meshio y subprocess.
2. MuestrearGenera puntos aleatorios, Poisson, semiuniformes y de rejilla.
3. TetraedralizarUsa Delaunay, PyVista o TetGen según la estrategia.
4. InspeccionarConstruye una malla VTK y muestra una sección inferior.
5. ExportarEscribe los puntos y llama al ejecutable TetGen.

2. Orden de ejecución

3. Imports y dependencias

NumPy y SciPy

numpy crea y transforma arrays. qmc.PoissonDisk genera muestras espaciadas. Delaunay crea tetraedros a partir de puntos.

PyVista y VTK

Construyen objetos de malla, convierten celdas y muestran una representación 3D estática.

TetGen y meshio

El paquete Python tetgen genera la malla semiuniforme. meshio escribe los puntos en formato que luego lee el ejecutable TetGen.

Imports no usados

matplotlib, PatchCollection, tri, varios tipos VTK y meshzoo no participan en el flujo activo actual.

4. Visualización con plot_pyvista

La función recibe nodes con forma N x 3 y simplices con forma M x 4. Cada fila de simplices identifica los cuatro vértices de un tetraedro.

Formato VTK
# VTK necesita [numero_de_vertices, i, j, k, l]
buf = np.empty((len(simplices), 1), pv.ID_TYPE)
buf[:] = 4
elements = np.hstack((buf, simplices)).flatten()
cell_type = np.empty(len(simplices), dtype='uint8')
cell_type[:] = 10  # VTK_TETRA
grid = pv.UnstructuredGrid(elements, cell_type, nodes)

Después calcula los centroides, conserva las celdas cuyo centro cumple z < 0.5, dibuja esa mitad inferior y superpone un cubo rojo en modo wireframe.

Suposición: cells.reshape(-1, 5)[:, 1:] solo es válido si todas las celdas son tetraedros y cada una ocupa cinco posiciones en el array VTK.

5. Ajuste de puntos a la frontera

add_box añade las ocho esquinas del cubo, elimina duplicados exactos y pasa todos los puntos por move_point.

Frontera del cubo
box = [[0,0,0], [0,0,1], ...]
arr = np.append(arr, box, axis=0)
arr = np.unique(arr, axis=0)

for i in range(0, len(arr)):
    new_p = move_point(1, arr[i,0], arr[i,1], arr[i,2], tolerance)
    arr[i] = new_p

move_point fija una coordenada a 0 si está cerca de la cara inferior o a 1 si está cerca de la cara superior. Como la corrección se hace coordenada por coordenada, puede crear puntos coincidentes.

Advertencia: numVertices - 8 intenta compensar las ocho esquinas, pero el número final puede cambiar por duplicados. El notebook no valida después si existen puntos repetidos o tetraedros degenerados.

7. Malla aleatoria

La sección titulada “Uniform” genera puntos independientes uniformemente distribuidos, no una rejilla regular. Luego aplica Delaunay en tres dimensiones.

Random + Delaunay
RandomSample = np.random.rand(numVertices - 8, 3)
RandomSample = add_box(RandomSample, tolerance)
randomDelaunay = Delaunay(RandomSample)

plot_pyvista(randomDelaunay.points, randomDelaunay.simplices)

El resultado principal es randomDelaunay.points para los vértices y randomDelaunay.simplices para la conectividad de los tetraedros.

8. Malla Poisson disk

Poisson disk intenta separar los puntos para evitar agrupaciones demasiado densas.

Poisson disk
rng = np.random.default_rng()
engine = qmc.PoissonDisk(d=3, radius=radius, seed=rng)
sample = engine.fill_space()
sample = add_box(sample, tolerance)
poissonTriangulation = Delaunay(sample)

poissonPoints = sample
poissonTriangles = poissonTriangulation.simplices.copy()

El número final depende de radius, de la frontera añadida y del generador. Como default_rng() no recibe una semilla explícita, dos ejecuciones pueden producir resultados diferentes.

9. Malla semiuniforme con TetGen Python

Esta estrategia no empieza con puntos interiores. Describe la superficie del cubo con ocho vértices y doce triángulos, y deja que TetGen cree una malla de calidad.

PLC del cubo
v = np.array([[0,0,0], [1,0,0], ...])
f = np.vstack([[0,1,2], [2,3,0], ...])

tgen = tetgen.TetGen(v, f)
SemiUniformPoints, SemiUniformTriangles, _, _ = tgen.tetrahedralize(switches="pqa" + areaMax)
SwitchFunción conceptual
pTrata la entrada como una geometría PLC.
qSolicita control de calidad.
aLimita el volumen máximo de los tetraedros.

10. Grid uniforme

La celda anterior de grid está completamente comentada. La celda activa crea lnspace puntos por eje y después aplica Delaunay 3D mediante PyVista.

Grid + VTK
points = np.array([
    [i / (PointsperLine - 1),
     j / (PointsperLine - 1),
     k / (PointsperLine - 1)]
    for k in range(PointsperLine)
    for j in range(PointsperLine)
    for i in range(PointsperLine)
])

grid = pv.StructuredGrid()
grid.points = points
grid.dimensions = (PointsperLine,)*3
tetrahedralized = grid.cast_to_unstructured_grid().delaunay_3d(alpha=1.0)

Finalmente extrae UniformPoints y uniformTriangles. La variable se llama “triangles” por herencia del notebook, pero cada fila representa cuatro índices y corresponde a un tetraedro.

12. Llamada al TetGen ejecutable

La última celda localiza el binario compilado por CMake. La búsqueda contempla tanto generadores multi-config como Ninja.

subprocess
tetgen_candidates = [
    os.path.abspath("../tetgen/build/Release/tetgen.exe"),
    os.path.abspath("../tetgen/build/tetgen.exe"),
]
tetgen_exe = next((path for path in tetgen_candidates if os.path.isfile(path)), None)

result = subprocess.run(
    [tetgen_exe, "-fzenn", mesh_file],
    capture_output=True,
    text=True,
)

El comando -fzenn pide archivos de caras, aristas y vecinos, y utiliza índices empezando en cero. Si el proceso falla, la celda imprime la salida y lanza RuntimeError.

Prerequisito: compila TetGen antes de ejecutar esta celda: cmake -S .\tetgen -B .\tetgen\build -DBUILD_EXECUTABLE=ON -DBUILD_LIBRARY=OFF y luego cmake --build .\tetgen\build.

14. Advertencias importantes

  • Reproducibilidad: random y Poisson no usan una semilla fija.
  • Puntos repetidos: add_box puede introducir coincidencias después de ajustar la frontera.
  • Conteos variables: Poisson no garantiza exactamente numVertices.
  • Tipos de celda: el reshape del grid presupone que todo son tetraedros.
  • Directorio de trabajo: las rutas relativas ../data y ../tetgen/build presuponen que el notebook se ejecuta desde notebooks.
  • Visualización parcial: plot_pyvista muestra solo centroides con z < 0.5, no toda la malla.
