# Polylla3D - Polyhedral Mesh Generation and Analysis

## Overview

Polylla3D is a Python library for generating and analyzing 3D polyhedral meshes using different sampling strategies. It provides tools to:

- Generate tetrahedral meshes using multiple point distribution methods:
  - **Random Sampling**: Uniformly random point distribution
  - **Poisson Disk Sampling**: Evenly distributed points using Poisson disk algorithm
  - **Semi-uniform Sampling**: Constrained mesh generation with area constraints
  - **Uniform Grid**: Regular grid-based sampling

- Analyze mesh topology and geometry
- Extract polyhedral decompositions using edge and face-based strategies
- Generate OFF format mesh files for visualization

## Core Components

### Mesh Data Structures (`src/mesh.py`)

- **Vertex**: Represents a 3D point with coordinates
- **Edge**: Connects two vertices
- **Face**: Triangle face defined by three vertices
- **Tetrahedron**: 3D element with four vertices
- **TetrahedronMesh**: Main mesh container with complete topological information

### Polyhedral Decomposition

**PolyllaEdge** (`src/PolyllaEdge.py`):
- Decomposes tetrahedral meshes into polyhedra based on longest edges
- Detects and repairs barrier edges (edges with hanging tetrahedra)
- Uses depth-first search traversal

**PolyllaFace** (`src/PolyllaFace.py`):
- Decomposes meshes using face-based metrics (area, aspect ratio, incircle, circumcircle)
- Identifies and repairs polyhedra with barrier faces
- Supports multiple quality metrics: `'r'`, `'R'`, `'tra'`, `'are1'`, `'are2'`, `'a'`

### Utility Functions (`src/utils.py`)

- `ccw_check()`: Counter-clockwise orientation check
- `calculate_face_normal()`: Compute face normal vectors
- `is_polyhedron_convex()`: Check if a polyhedron is convex

## Quick Start

### Interactive Tutorial (Jupyter)

Open and run the notebook to interactively generate meshes:

```bash
jupyter notebook notebooks/3D-samplegeneration.ipynb
```

The notebook demonstrates:
1. Importing required libraries
2. Configuring mesh parameters (number of points, sampling radius, etc.)
3. Generating meshes using different methods
4. Visualizing meshes with PyVista
5. Exporting meshes to node files

### Configuration Parameters

In the notebook, choose your configuration (edit Cell 2):

```python
# Example: 1000 vertices configuration
tolerance = 0.1              # Distance from boundary for edge snapping
numVertices = 1000          # Target number of points
radius = 0.084              # Poisson disk radius
areaMax = "0.00038"         # Max area constraint for semi-uniform
lnspace = 10                # Points per dimension for uniform grid
```

Available presets: 500, 1000, 5000, 10000, 50000 vertices

### Running Scripts Directly

#### Generate and analyze edge-based decomposition:
```bash
python src/PolyllaEdge.py
```

#### Generate and analyze face-based decomposition:
```bash
python src/PolyllaFace.py
```

Both scripts:
- Read mesh files from `data/` directory
- Process and decompose the mesh
- Generate statistics and OFF files
- Save results to `data/` directory

## Output Files

After running the notebook:

- `{numVertices}random.node` - Random sampling result
- `{numVertices}poisson.node` - Poisson disk sampling result
- `{numVertices}semiuniform.node` - Semi-uniform sampling result
- `{numVertices}uniform.node` - Uniform grid result

Additional files generated by tetgen:
- `.ele` files (tetrahedral elements)
- `.face` files (surface faces)
- `.edge` files (mesh edges)

## Usage Example

```python
from src.mesh import TetrahedronMesh
from src.PolyllaEdge import PolyllaEdge

# Load mesh files
mesh = TetrahedronMesh(
    node_file="data/socket.1.node",
    face_file="data/socket.1.face", 
    tetra_file="data/socket.1.ele",
    edge_file="data/socket.1.edge"
)

# Generate edge-based polyhedra
polylla = PolyllaEdge(mesh)

# Get statistics
polylla.get_info()
```

## Performance Notes

- **Small meshes** (100-1000 vertices): Run in seconds
- **Medium meshes** (5000 vertices): Run in 1-2 minutes
- **Large meshes** (50000+ vertices): May take several minutes

For faster mesh generation:
1. Reduce mesh complexity
2. Use simpler quality metrics in PolyllaFace
3. Parallel processing can be added for future versions

## References

The polyhedral decomposition algorithms are based on:
- Edge-based decomposition: Longest edge refinement strategies
- Face-based decomposition: Quality-metric driven decomposition
